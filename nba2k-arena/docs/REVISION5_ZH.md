# Revision 5：照片中的浅灰球场涂装

R5 在已校验的 R4 上补充浅灰中圈圆盘，以及两端的完整罚球区矩形与向中场凸出的罚球半圆。五张照片共同定义一个球场；人物不属于建模目标。参考中的干燥哑光地面作为材质基准，不复刻第五张湿地面的镜面反射。

## 保留与新增

保留 R4 的草台、路灯、看台、桶组、棕榈树和室外场景；保留全部原场地尺寸、白线/暗色标记、篮筐锚点、碰撞与玩法数据。现有 floor 的完整顶点/索引前缀和每个 Prim 记录都逐字保留。只向同一个 floor Model 追加浅灰几何，并增加独立材质与贴图，不修改原 Object、Effect 或编译后的 shader。

浅灰材质与深灰底场使用同一份 4096² 水泥扫描来源，保留颗粒尺度和完整 13 层 mip；新的编码 RGB 目标为 `[143,147,148]`，是视觉校色值，不是照片测得的物理反照率。所有四组 UV 都在原底面三角形上插值，沿用原编码；法线和粗糙度继续引用已经核查过通道的原有 floor 贴图。新增材质完整复制 base floor 的受光路径，避免误用白线材质的另一套 UV 采样。

当前标准场地保留 16 英尺罚球区和 12 英尺罚球圆，矩形比圆宽，因此结合处各有 2 英尺肩部。照片无法提供可靠尺量；本版按用户指定的标准篮球标线与受保护的现有几何涂装，不为了图片透视去移动玩法边界。

## 白线覆盖与精度

原白线材质不写深度。仅把填充层设置在底面与白线之间，仍不能保证原生批次排序后白线不被覆盖。因此填充几何扣除实际 R4 导出标线三角形占据的区域，并对最终 float32 顶点做独立三角形交叠检查。检查器使用顶点包含和线段相交，与生成器的半平面裁切算法独立。

首次无余量裁切在实际 float32 中出现约 0.45 微米宽的交叠，有理数计算也确认了该问题。最终给裁切轮廓每个 XZ 分量增加 1.25 微米数值余量，略大于此球场的最大 float32 ULP 1.2207 微米；使用三角形与微小正方形的凸包，避免锐角偏移产生长尖角。独立检查仍按每对三角形交叠面积 `1e-5 cm²` 的原阈值执行，不通过即拒绝打包。这不是肉眼可见的黑色边框。

新材质在已有颜色、深度预通过程、镜面和电影路径上设置 `DEPTHBIAS=-4`、`SLOPESCALEDEPTHBIAS=0`，保留原 stencil、ZWRITE 和原生资源连接。最初 −2/−2 在实际导出几何的 WebGL 预览中露出局部底色；几何覆盖及独立纯色诊断确认是深度问题，固定 −4/0 消除了已观察到的暗斑。固定项采用原白线已有的 −4，去掉微小三角形可能放大的斜率项。它仍是需要 NBA 2K 实测的候选状态；不抬高几何、不关闭深度测试、不改已有白线状态。

## 构建和验证

```sh
python3 nba2k-arena/scripts/build_revision5.py
python3 -m unittest discover -s nba2k-arena/tests -v
python3 nba2k-arena/scripts/revision5_preview.py --three-dir /path/to/three
```

脚本核对受保护 donor、R4 主 IFF 和同编号配套地板的 SHA-256。旧归档成员中仅 `level.SCNE` 可变，已有二进制资源全部保留；IFF 内使用 ZIP_STORED，分发 ZIP 仅做外层无损压缩。完整候选及分发校验通过后才替换本地 R5 输出。不会安装建模软件、写入游戏目录或启动游戏。

导出几何与颜色的 Three.js 预览用于检查涂装、标线和结构；它没有执行 NBA 2K 的 shader 或渲染路径。原生天空曝光、树木受光与阴影、低角度地板深度偏移、篮架资源及实际玩法仍需要游戏侧验证。缺失的篮架缓冲尚未补齐，现有室内 donor 篮架不能标为已彻底替换。

交付位置为 `output/revision5/venice_court_revision5.zip`，具体哈希与检查结果见 `build/revision5/revision_report.json` 和 `output/revision5/validation.json`。R5 属本地候选，公开推送需要解决此前自动审批提出的具体候选包发布确认。

最终本地包为 84,225,749 字节，SHA-256 `1ad99e1a5047ea094bf9b68196a996b5bbe301fad27455a60c096004f3a8c01a`。全部 144 项测试通过，日志见 `revision5_tests.txt`。原生 floor 总计 63,641 顶点，仍在 R16 范围内；新增 40,686 个填充三角形。独立实际浮点交叠审计无超出 `1e-5 cm²` 阈值的三角形对。最终俯视、中圈近景及罚球区近景已复核，见 `revision5_preview_audit.json`；深度问题的诊断与边界记录在 `revision5_depth_diagnostic.md`。
