# Revision 6：阶段收尾与质量报告

按用户“细节做到约九成即可先推送、然后停工”的最新要求，本轮只收尾已发现的海岸缺口、接缝和灰色建筑，不继续扩大制作范围。交付是可供游戏侧测试的候选；“九成”作为停止继续打磨的阶段要求，不能换算为未经实测的精确还原率或游戏完成率。

## 本轮改动

R5 的远处步道、沙坡、草地在不同位置结束，实际导出地形存在缺面；海面与近岸共用过大的量化范围，也造成厘米级接缝。R6 分离相关地形，沿用原生可解码的统一位置缩放格式，填补缺口并对最终二进制重新检查。保留原草台、promenade 和既有 Object 变换，不通过移动球场或植物来掩盖问题。详见[原生海岸审计](revision6_coast_audit.md)及本轮构建报告。

五张原图支持远端低宽灰色体块、薄顶口和浅色矩形分格，无法确认此前的三扇黑门及银色把手。R6 保留主体包络，移除这些缺乏依据的细节，使用哑光灰墙与浅分格。灰墙贴图从现有 4096² 混凝土纹理调色，保持分辨率并复用原粗糙法线；没有加入新门窗、标牌或用途设定。[建筑参考判读](revision6_building_reference.md)明确区分照片证据与设计近似。

全部五张参考图的 AI 增强已完成，原图 640×480、工具实际输出 1448×1086；原图保留不变。AI 补出的纹理、树叶和标识细节不是实测资料。[增强图与来源记录](../textures/source/references/enhanced/README.md)包含逐张对应和哈希。

## 当前质量判断

| 项目 | 已完成与证据 | 仍有的边界 |
|---|---|---|
| 整体外观 | 同一开放海边球场的布局、棕榈、分层草台、银色看台、双头路灯与桶组已组成连续场景 | 照片没有测量数据，摆位和尺寸含设计近似 |
| 球场与地面 | 标准白线、中圈、浅灰中圈及罚球区、4K 哑光水泥；R5 实际浮点裁切和预览检查已记录 | 保留的 16 英尺罚球区与照片透视存在差别；低角度深度偏移仍需游戏验证 |
| 结构和材质 | 真实几何、连续法线、完整 mip；本轮修补实际海岸缺面和无依据的建筑细节 | Three.js 预览没有执行 NBA 2K 的着色器和原生日照 |
| 原生包 | 检查原有资源保护、索引/流长度、ZIP CRC 和 SHA；仅新增资源并修改两个生成场外 Model | 尚未实际加载 NBA 2K，不能将静态通过视为游戏通过 |
| 篮架 | 原篮筐位置、动画、碰撞和游戏引用保持 | 主篮架仍缺四个外部缓冲，室内 donor 支架/计时器未完成室外细立柱替换；预览中六个篮架实例仍为边界框 |

天空曝光、棕榈受光/投影、原生材质调度、远景裁剪及玩法仍需游戏侧测试。现有证据不能宣称之前用户截图中的黑树等问题已经在游戏里全部消除。这些限制随候选一起交付，不以额外的预览美化替代验证。

