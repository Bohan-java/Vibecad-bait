## 发现

- 正常 11 号主包与地板共包含 1,169 个 DDS 文件，SCNE 仍沿用原始 TLD 引用及压缩元数据。模型也采用 `.gz` 引用对应同名 `.bin` 的方式。
- R7.2 主包的 802 个 TLD 都已经展开成完整像素数据。其中许多原材质仍带有压缩用的 `CompressionMethod: 33` 和 `Segments`，这些偏移不对应包中已经展开的数据。之前没有沿用可用 MOD 的 DDS 替代方式。
- 当前使用的完整原生材质 Effect、Technique、26 个着色器二进制和脚本，与正常 11 号对应材质相同。83 个生成模型的 701,412 个顶点、索引和变换没有发现非有限数或退化切线基问题。
- 后处理数据与原 donor 完全相同。没有依据继续更换后处理参数或编造新的渲染通道。

这不是根据通用 ZIP 解压成功推断游戏兼容。开发者 looyh 对 [NBA2K25 File Explorer 完整转码导出方式](https://www.nba-live.com/forums/viewtopic.php?t=116315)的说明也明确描述了 `.tld` 转 `.dds`、`.gz` 转 `.bin`，场景仍可沿用原始引用扩展名。该说明支持本次采用的资源替代约定，NBA 2K26 上的最终结果仍以用户直播为准。

## 本次改动

全部 802 个 TLD 改为相同名称主体的 DDS；两层光照保持为两层 Texture2D 数组，全部 mip 层与像素块逐字节保留。IFF 使用与正常参考文件一致的 ZIP_DEFLATED。

SCNE、灯光、曝光、材质参数、模型、着色器、篮筐、标线、碰撞和玩法数据，与 R7.2 保持相同。配套 floor 的场景内容不变；它本身没有 TLD，仅重新封装 ZIP。这样实际反馈能判断贴图封装修正的效果，不会混入新的亮度估值。
