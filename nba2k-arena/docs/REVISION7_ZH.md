最新状态：**R7 已被用户实测否定：整个三维场景全黑，只剩玩家标识等界面可见。** 下列内容是历史修改记录，不能作为修复完成的依据。下一步在本地处理 [R7.1 曝光复原](REVISION7_1_ZH.md)，等待用户截图确认；未确认正常前不再推送调整包。

此前，2026-09-06 用户提供的三张实测截图显示 R6 的人物、篮架和地面大面积泛白，棕榈树及场外地面几乎全黑。静态检查和网页几何预览不能证明原生渲染正确；R6、R7 的显示结果均已被实际反馈否定。

## 静态光照绑定依据

直接读取 IFF 中已有的 Hires/Lores 着色器：`PS.0b7b9c751b052066.shader`、`PS.04f29b4000dbd424.shader`，其共同顶点着色器为 `VS.4c2ad8d7d9685f81.shader`。分析仅发生在临时副本，交付内的编译着色器全部保留。

- 两个像素着色器均从实例数据读取纹理描述符；描述符为 0 时，静态辐照度分支输出 0。是否由游戏成功分配非零描述符仍待运行验证。
- 原始 Object 名与对应 Texture 名相同，线光 Texture 使用同名加 `_linelightvisibility`；R7 沿用这一已存在的关联方式，每个实例单独建立两个 Texture 记录，共享两份小型像素资源。
- 48 字节 UserData 的 +16 字段包含整数图集标志、层数及两个 14 位范围，+20 为两个 16 位图集尺寸，+24 为图集偏移。新生成的 16×16 数据与场景中已有 16×16、双层实例数据逐字节一致；1944×1944 的编码也与原始 apron 实例一致。这些字段是采样布局数据。
- UV7 经原始 VS 输出至 TEXCOORD4.zw，Hires/Lores PS 从这里读取静态光照 UV。83 个相关网格原有的 UV7 均实际读取并确认全 0，只有其解码偏移改变，所有原始二进制保持一致。
- 光照资源使用 16×16、2 mip、2 face 的 `R11G11B10_FLOAT` 原生线性 TLD；层 0 与现有地面使用相同的环境填充值，层 1 为 (0.5, 0.5, 1)，表示均匀环境成分。它是避免无光照的近似填充，不是空间烘焙或最终日影质量。
- 恢复原始 Hires/Lores 的真实 GBuffer、阴影、深度、反射等 Technique/Pass，未将 Forward 像素着色器伪装成 GBuffer 通道，也未用自发光代替受光。
