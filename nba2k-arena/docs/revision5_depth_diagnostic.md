# R5 导出画面的局部深度诊断

这是本地 Three.js 0.180.0 对实际 IFF 几何的诊断，不是 NBA 2K 运行结果。检查机位为 `[0,1200,1050]` 朝向 `[0,0,1050]`；原始候选使用新增填充深度状态 −2/−2。

在罚球圈后半段下方，约 X=20…25 cm、Z=1045…1055 cm 处观察到小块底色。直接检查导出坐标的 5 个样本都有一个填充三角形覆盖，且无标线三角形；因此不是应保留的暗色 lane 标记。纯红填充、原贴图、无光照填充的对照均能看到缺口。仅取消 floor 投影阴影、改用朝上预览法线也未消除问题。

临时关闭填充的深度测试/写入后缺口消失，确认深度路径相关；这两个诊断设置均没有写入候选。只把斜率偏移设为 0、固定偏移仍为 −2 时也没有消除。改为固定偏移 −4、斜率偏移 0，恢复 PBR、深度测试和写入后，已观察到的缺口消失。

最终候选采用原白线已使用的固定项 −4，并以 0 斜率项避免微小裁切三角形的数值斜率放大。原材质、白线状态、编译后 Effect 和原资源不改；所有新 fill 的既有颜色/深度预通过程/镜面/电影路径一致更新。最终预览从新候选重新导出，没有保留纯红、无光照、禁用深度、强制法线或禁用 floor 阴影的诊断覆盖。

该对照只能证明本预览的现象与解决方式。它不证明 WebGL 与 NBA 2K 的深度偏移单位完全一致，也不替代低角度、远近镜头、人物脚部和篮架接地的原生检查。
