# AI-enhanced reference set

These five images are enhanced versions of the same five original photographs,
not new camera views or five separate courts. People are not modelling targets.
The originals in the parent folder are retained unchanged and remain the spatial
reference. AI-added surface, foliage and signage details are not measured facts.

Generated with the built-in image generation tool at the user's request.
Requested 3072 × 2304; the tool returned 1448 × 1086 for each image. No subsequent
resampling or artificial enlargement was applied. Original dimensions: 640 × 480.
The composition was visually compared against all five originals; this is not a
pixel-exact reconstruction of lost detail. The fifth original is visibly wetter
than the first four; the playable court targets the user's requested dry finish.

The exact prompt set is saved in `prompts.json`; file hashes and source mapping
are in `manifest.json`.
